# Design Specification: ระบบคำสั่งโรงเรียน (School Orders Management System)

- **วันที่จัดทำ:** 23 ตุลาคม 2026
- **สถานะ:** ร่างแบบระบบเพื่อขอความเห็นชอบ (Draft for Review)
- **ระบบ:** e-Saraban โรงเรียนสวนกุหลาบวิทยาลัย (จิรประวัติ) นครสวรรค์
- **ผู้รับผิดชอบหลัก:** Antigravity AI Assistant & Engineering Team

---

## 1. บทนำและวัตถุประสงค์ (Intent & Objectives)
ระบบคำสั่งโรงเรียน (School Orders System) มุ่งเน้นการจัดทำ ทะเบียน ออกเลข คุมเล่ม และจัดเก็บคำสั่งโรงเรียนสวนกุหลาบวิทยาลัย (จิรประวัติ) นครสวรรค์ ให้ถูกต้องตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 และสอดคล้อง 1:1 กับไฟล์แบบฟอร์มทางการ `แบบฟอร์ม_คำสั่ง.docx`

### เป้าหมายหลัก (Goals)
1. **แบบฟอร์มตรงตามมาตรฐาน 1:1:** สร้างและแก้ไขคำสั่งผ่านฟอร์มกระดาษ A4 เสมือนจริง (WYSIWYG Interactive Paper) ตรงตามสเปกของไฟล์ Word `แบบฟอร์ม_คำสั่ง.docx` (ครุฑกลาง 3 ซม. หัวคำสั่งกึ่งกลาง 16pt หนา ย่อหน้า 2.5 ซม. วันสั่งการ และส่วนลงนาม)
2. **ระบบทะเบียนและออกเลขคำสั่งอัตโนมัติ (Order Running Number):** รองรับการออกเลขที่คำสั่งประจำปี พ.ศ. อัตโนมัติ (เช่น `ที่ 1/2569`, `ที่ 2/2569`) พร้อมตัวเลือกกำหนดเลขด้วยตนเอง
3. **คลังคำสั่งโรงเรียนและดาวน์โหลดเอกสาร (Orders Repository):** จัดเก็บคลังคำสั่งของโรงเรียน ค้นหาและกรองตามหมวดหมู่งาน เพื่อให้ครูและบุคลากรนำไฟล์คำสั่ง (PDF) ไปแนบใน **"ระบบขออนุมัติไปราชการ"** ได้โดยตรง
4. **ลงนามอิเล็กทรอนิกส์และแนบไฟล์ฉบับจริง (Hybrid Signing & File Upload):** รองรับทั้งการพิมพ์กระดาษเพื่อลงนามจริง, การลงนาม 1-Click ด้วยลายเซ็นดิจิทัลของผู้อำนวยการ, และการอัปโหลดไฟล์สแกนคำสั่งต้นฉบับ (PDF)

## 2. การวิเคราะห์โครงสร้างไฟล์แบบฟอร์มทางการ (`แบบฟอร์ม_คำสั่ง.docx`)
จากการวิเคราะห์ไฟล์ OpenXML Word (`word/document.xml`) ได้ข้อกำหนดทางเทคนิคดังนี้:

| องค์ประกอบ | ค่ากำหนดทางเทคนิค (Word 1:1) | การนำมาใช้ในระบบ (CSS/HTML) |
|---|---|---|
| **ขอบกระดาษ (Margins)** | บน 1.5 ซม., ซ้าย 3.0 ซม., ขวา 2.0 ซม., ล่าง 2.0 ซม. | `padding: 1.5cm 2cm 2cm 3cm;` ทั้งจอภาพและการพิมพ์ |
| **ตราครุฑ (Garuda)** | กว้าง 2.73 ซม. สูง 3.0 ซม. กึ่งกลางหน้ากระดาษ | `assets/img/krut_thai.png` (30mm x 27.3mm) จัดกึ่งกลาง |
| **ชื่อคำสั่ง (Header)** | `คำสั่งโรงเรียนสวนกุหลาบวิทยาลัย (จิรประวัติ) นครสวรรค์` | `font-size: 16pt; font-weight: bold; text-align: center;` |
| **เลขที่คำสั่ง** | `ที่  [เลข]/[ปี พ.ศ.]` | `font-size: 16pt; font-weight: bold; text-align: center;` |
| **เรื่องคำสั่ง** | `เรื่อง  [ชื่อเรื่องคำสั่ง]` | `font-size: 16pt; font-weight: bold; text-align: center;` |
| **เส้นคั่น (Divider)** | เส้นแบ่งบรรทัดกึ่งกลางหน้ากระดาษ | `border-bottom: 1px solid #000; width: 60%; margin: 8px auto;` |
| **เนื้อความคำสั่ง** | ย่อหน้า 2.5 ซม. (`text-indent: 2.5cm`) สระโปร่ง Thai Distribute | `text-indent: 2.5cm; text-align: justify; line-height: 1.25;` |
| **ย่อหน้าบังคับใช้** | `ทั้งนี้  ตั้งแต่  [วัน เดือน ปี] เป็นต้นไป` | `text-indent: 2.5cm; font-size: 16pt;` |
| **วันสั่งการ** | `สั่ง  ณ  วันที่  [วันที่]  [เดือน]  พ.ศ.  [ปี]` | เยื้องกึ่งกลางหน้ากระดาษ (`padding-left: 7.5cm;`) |
| **ส่วนลงนาม** | เว้นระยะ 3-4 บรรทัด `( ชื่อเต็ม )` และ `ตำแหน่ง` | จัดกึ่งกลางชื่อเต็ม โดยไม่มีข้อความกลุ่มสาระ |

## 3. สถาปัตยกรรมระบบ (System Architecture & Database)

### 3.1 ฐานข้อมูล (Database Schema)
ใช้ตาราง `documents` หลักร่วมกับประเภทเอกสาร `doc_type = 'order'` เพื่อความสมบูรณ์และสามารถเชื่อมโยง Audit Log, Document Routes, Document Links ได้ทันที พร้อมรองรับคอลัมน์เฉพาะของคำสั่ง:

- `doc_type`: `'order'`
- `doc_no`: เลขที่คำสั่ง เช่น `1/2569`
- `year`: ปี พ.ศ. เช่น `2569`
- `title`: เรื่องคำสั่ง
- `content`: ข้อความคำสั่งฉบับเต็ม (HTML/Rich-text พร้อมตัดคำภาษาไทย)
- `order_effective_text`: ข้อความบังคับใช้ เช่น `"ทั้งนี้ ตั้งแต่วันที่ ๑ พฤษภาคม พ.ศ. ๒๕๖๙ เป็นต้นไป"`
- `doc_date`: วันที่สั่งการ
- `from_org`: ผู้มีอำนาจสั่งการ (เช่น ผู้อำนวยการโรงเรียนสวนกุหลาบวิทยาลัย (จิรประวัติ) นครสวรรค์)
- `to_org`: ผู้รับคำสั่ง/หน่วยงานที่เกี่ยวข้อง
- `file_path`: ไฟล์ PDF ต้นฉบับแนบ
- `status`: `'draft'` (แบบร่าง), `'published'` (เผยแพร่/มีผลบังคับใช้), `'canceled'` (ยกเลิก)
- `creator_signature`: รูปลายเซ็นผู้สร้าง/ผู้ออกคำสั่ง

### 3.2 สถาปัตยกรรม MVC & Routing
- **Controller:** `App\Controllers\OrderController`
- **Model:** `App\Models\DocumentModel`, `App\Models\DocumentLogModel`
- **Views Directory:** `app/Views/orders/`
  - `index.php`: หน้ารวมทะเบียนคำสั่งโรงเรียน พร้อมตัวกรองปี พ.ศ. ค้นหา และปุ่มสร้างคำสั่ง
  - `create.php`: หน้าพิมพ์สร้างคำสั่งแบบกระดาษ A4 เสมือนจริง 1:1
  - `edit.php`: หน้าแก้ไขคำสั่ง
  - `view.php`: หน้าพรีวิวคำสั่ง แสดงรายละเอียด วันที่สั่งการ ไฟล์แนบ และสถานะ
  - `print.php`: หน้าพิมพ์เอกสารคำสั่ง A4 มาตรฐาน 1:1 ไร้ส่วนหัว/ท้ายเว็บ ปริ้นต์ได้ทันที

### 3.3 เส้นทาง URL (Routes)
- `GET  admin/orders` $\rightarrow$ `OrderController::index`
- `GET  admin/orders/create` $\rightarrow$ `OrderController::create`
- `POST admin/orders/store` $\rightarrow$ `OrderController::store`
- `GET  admin/orders/view/(:num)` $\rightarrow$ `OrderController::view/$1`
- `GET  admin/orders/edit/(:num)` $\rightarrow$ `OrderController::edit/$1`
- `POST admin/orders/update/(:num)` $\rightarrow$ `OrderController::update/$1`
- `POST admin/orders/delete/(:num)` $\rightarrow$ `OrderController::delete/$1`
- `GET  admin/orders/print/(:num)` $\rightarrow$ `OrderController::printDoc/$1`
- `POST admin/orders/upload/(:num)` $\rightarrow$ `OrderController::uploadFile/$1`
- `POST admin/orders/sign/(:num)` $\rightarrow$ `OrderController::sign/$1`

## 4. มาตรฐาน UI/UX และการเข้าถึงข้อมูล (UI/UX Standards)
1. **แถบเมนูหลัก (Sidebar Navigation):**
   - อัปเดตเมนู **"4. หนังสือสั่งการ -> ทะเบียนคำสั่งโรงเรียน"** ให้ชี้ไปยัง `/admin/orders` อย่างถูกต้อง พร้อม Badge แสดงจำนวนคำสั่งประจำปี
2. **หน้ากระดาษสร้างคำสั่ง (Paper Form Layout):**
   - ใช้ CSS `saraban-order.css` (หรือต่อยอดจาก `saraban-memo.css`) รองรับการตัดคำภาษาไทย (`Intl.Segmenter`) ปุ่ม "จัดคำไทยสวย" และแสดงผลบนเดสก์ท็อปและมือถืออย่างลงตัว
3. **การเข้าถึงสำหรับครูทั่วไป:**
   - ครูและบุคลากรทุกคนสามารถเข้าถึงแท็บ "คลังคำสั่งโรงเรียน" เพื่อค้นหาและดาวน์โหลดไฟล์คำสั่งนำไปแนบในการขอไปราชการได้สะดวกรวดเร็ว

## 5. แผนการตรวจสอบและทดสอบ (Verification Plan)
1. ตรวจสอบการรันเลขคำสั่งอัตโนมัติประจำปี พ.ศ. ให้ถูกต้องและไม่ชนกัน
2. ทดสอบการสร้างคำสั่ง พิมพ์เนื้อหาภาษาไทย พร้อมการตัดคำและระยะย่อหน้า 2.5 ซม.
3. ทดสอบหน้าพิมพ์ (`print.php`) เทียบกับไฟล์ `แบบฟอร์ม_คำสั่ง.docx` ให้ตรงกัน 1:1
4. ทดสอบการอัปโหลดไฟล์คำสั่ง PDF และเปิดอ่านไฟล์
5. ทดสอบการลงนาม 1-Click สำหรับผู้อำนวยการ
