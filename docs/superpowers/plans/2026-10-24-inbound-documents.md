# ระบบทะเบียนหนังสือรับภายนอก (Inbound Document Registration & Executive Endorsement System) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** พัฒนาระบบทะเบียนหนังสือรับ (รับเข้าจากภายนอก) สำหรับงานสารบรรณโรงเรียน รองรับการอัปโหลดไฟล์สแกน/PDF, รันเลขทะเบียนรับอัตโนมัติ, ปรับตำแหน่งตรายางรับบนเอกสาร, ส่งเกษียนเสนอ รอง ผอ./ผอ. สั่งการ และกระจายเรื่องมอบหมายงานไปยังครู/กลุ่มงานผู้รับผิดชอบ

**Architecture:** สถาปัตยกรรม MVC ตามมาตรฐาน CodeIgniter 4 โดยสร้าง `InboundDocumentController` ดูแลหนังสือรับเข้าภายนอก (`doc_type = 'in'`), บันทึกข้อมูลลงตาราง `documents` และสร้างเส้นทางเดินแฟ้มเกษียนลง `document_routes`, รองรับการแสดงผลไฟล์ PDF พร้อมตรายางรับดิจิทัล และระบบมอบหมายงานสู่ผู้ปฏิบัติงาน

**Tech Stack:** PHP 8+, CodeIgniter 4, MySQL (MariaDB), Bootstrap 5 (Sneat Admin Theme), PDF.js / Embed PDF Viewer, SweetAlert2 (app-swal.js), Google Fonts (K2D & Saraban)

---

## Global Constraints

- ยึดหลักระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ และแนวปฏิบัติโรงเรียนสวนกุหลาบวิทยาลัย (จิรประวัติ) นครสวรรค์
- กฎเหล็กความชัดเจนของสี (Tri-Master Color Contrast): ห้ามใช้ตัวหนังสือสีเดียวกับพื้นหลัง, Solid Badges เสมอ
- การตั้งชื่อไฟล์วิว: มีชื่อโฟลเดอร์หรือบริบทนำหน้า (`inbound_index.php`, `inbound_create.php`, `inbound_view.php`)
- ความปลอดภัย: ป้องกัน CSRF (`<?= csrf_field() ?>`), ป้องกัน XSS (`esc(...)`), และตรวจสิทธิ์ผู้ใช้งานใน Controller อย่างเข้มงวด

## Tasks Overview

### Task 1: ฐานข้อมูลและการอัปเดตสคีมา (Database Migration)
เพิ่มคอลัมน์มอบหมายงานในตาราง `documents`:
- `assigned_to_user_id` (INT NULL): ไอดีครู/บุคลากรที่ได้รับมอบหมาย
- `assigned_department` (VARCHAR(200) NULL): กลุ่มบริหาร/กลุ่มงานที่ได้รับมอบหมาย
- `dispatch_status` (ENUM('pending', 'dispatched') DEFAULT 'pending'): สถานะการกระจายเรื่อง

### Task 2: Controller & Model สำหรับหนังสือรับภายนอก (`InboundDocumentController.php`)
- `index()`: หน้ารายการทะเบียนหนังสือรับ (Search, Filter วันที่/ความเร่งด่วน/สถานะ)
- `create()`: หน้าฟอร์มสารบรรณลงทะเบียนรับ + อัปโหลดไฟล์สแกน PDF + แนะนำเลขทะเบียนรับถัดไป (`0001/2569`) + กำหนดเส้นทางเสนอ รอง ผอ./ผอ.
- `store()`: บันทึกข้อมูล อัปโหลดไฟล์ จัดเก็บเส้นทางเดินแฟ้ม
- `view($id)`: หน้าตรวจดูเอกสาร แสดงไฟล์ PDF พร้อมตรายางรับดิจิทัล + ประวัติการเกษียน + กล่องเกษียนสั่งการของ ผอ.
- `endorse($id)`: ผอ./รอง ผอ. ลงนามเกษียน + ระบุคำสั่งการ + เลือกมอบหมายกลุ่มงาน/ครู
- `dispatch($id)`: ส่งต่อ/กระจายเรื่องไปยังผู้รับผิดชอบ

### Task 3: หน้ารายการทะเบียนหนังสือรับ (`inbound_index.php`)
- ตารางทะเบียนหนังสือรับตามระเบียบสารบรรณ: เลขทะเบียนรับ, เลขที่หนังสือต้นทาง, วันที่รับ, จาก, ถึง, เรื่อง, ความเร่งด่วน, สถานะ, ผู้รับผิดชอบ
- ตัวกรองค้นหาด่วน (Search Filter) + ปุ่ม "ลงทะเบียนหนังสือรับใหม่" (สำหรับเจ้าหน้าที่สารบรรณ)

### Task 4: หน้าฟอร์มลงทะเบียนรับเข้า (`inbound_create.php`)
- อัปโหลดไฟล์ PDF/รูปภาพเอกสารต้นฉบับ
- กรอกข้อมูลหนังสือต้นทาง: เลขที่หนังสือ, วันที่ในหนังสือ, หน่วยงานต้นทาง, ถึง
- รันเลขทะเบียนรับอัตโนมัติ พร้อมตัวเลือกปรับเปลี่ยนวันที่และเวลารับ
- เลือกเส้นทางเดินแฟ้มเสนอ รอง ผอ. และ ผอ. อัตโนมัติ (Default Director Route)

### Task 5: หน้ารายละเอียดหนังสือรับ & กล่องสั่งการของ ผอ. (`inbound_view.php`)
- กล่องแสดงข้อมูลหนังสือรับ + ตรายางรับดิจิทัล (เลขทะเบียนรับ วันที่ เวลา ผู้รับ)
- ฝังโปรแกรมดูเอกสาร PDF (Embedded PDF Viewer)
- กล่องลงนามเกษียนสำหรับ รอง ผอ. และ ผอ. พร้อมเมนู "คำสั่งการ" และตัวเลือก "มอบหมายกลุ่มงาน / เลือกครูผู้ปฏิบัติงาน"
- เมื่อ ผอ. ลงนามสำเร็จ ระบบจะแสดงป้ายชื่อผู้รับมอบหมาย และสถานะสำเร็จ

### Task 6: เชื่อมโยงระบบนำทางและเมนู (Routes & Sidebar Navigation)
- อัปเดต `app/Config/Routes.php` ให้รองรับ `/admin/inbound` และ `/admin/documents?type=in`
- อัปเดตเมนูใน `app/Views/layouts/main.php` เมนู "1. หนังสือภายนอก > ทะเบียนหนังสือรับ" ให้เปิดใช้งานได้อย่างสมบูรณ์
